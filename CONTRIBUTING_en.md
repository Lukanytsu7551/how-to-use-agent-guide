# Contribution Guide

Thank you for improving How to Use Agent. Each contribution should help readers complete a real task faster and leave behind a method that can be verified, reused, and adapted.

## Contributions Welcome

- Fix broken links, outdated screenshots, typos, and inaccurate statements.
- Add reproducible Codex or WorkBuddy tutorials, cases, and troubleshooting notes.
- Improve learning paths, navigation, search, responsive behavior, and accessibility.
- Add verified product updates with a source and review date.

## Content Standards

1. **Reproducible**: include environment, inputs, key steps, deliverables, and expected results.
2. **Verifiable**: explain how readers can confirm success.
3. **Bounded**: distinguish product facts, personal experience, and applicable conditions.
4. **Safe**: explain permissions, risks, and human confirmation points for files, accounts, credentials, publishing, and external actions.
5. **Respectful**: do not submit personal data, credentials, internal material, or content you cannot publish.

## Local Validation

```bash
pnpm install
pnpm run build
pnpm test
```

Before opening a pull request, confirm that edited pages and internal links work, media loads, text does not overlap on desktop or mobile, and no secrets or generated files are included.

## Pull Requests

Describe what changed, why it is needed, how it was validated, and any source plus review date for product-fact updates. Keep each pull request focused on one topic.
