# How to Use Agent

A Chinese learning center for choosing agents, understanding their foundations, and building reliable workflows.

[Read online](https://lukanytsu7551.github.io/how-to-use-agent-guide/) · [Contributing](./CONTRIBUTING_en.md) · [Security](./SECURITY.md) · [Code of Conduct](./CODE_OF_CONDUCT.md)

## Guides

| Guide | Best for | Focus |
| --- | --- | --- |
| Codex Guide | Coding, terminal tasks, refactoring, and complex development | App, CLI, IDE, MCP, project rules, and engineering workflows |
| WorkBuddy Guide | Office work, file processing, desktop automation, and collaboration | Setup, practical tasks, Skills, connectors, automation, and multi-agent collaboration |
| Agent Guide | Systematic study of agent principles and engineering methods | Loops, tools, context, memory, orchestration, governance, and long-running runtimes |

## Learning Path

1. Choose Codex or WorkBuddy when you need to complete a concrete task, based on the task, environment, and learning threshold.
2. Complete installation, sign-in, and a first verifiable task in the selected product guide.
3. Reproduce a relevant real-world case, then expand into configuration, integrations, automation, and collaboration.
4. Use Agent Guide when you want a systematic foundation: read the preface, Part 1, and then the book-style Parts 1–10 and appendices.
5. Troubleshoot issues in the order of installation, sign-in, usage, integrations, and feedback.

The current Agent Guide follows “Preface → Parts 1–10 → 45 chapters → Appendices”. Earlier Agent quick-start, recipe, and advanced pages remain as compatibility routes but are no longer the primary navigation.

## Local Development

Node.js 22 and pnpm are required.

```bash
pnpm install
pnpm run dev
pnpm run build
```
