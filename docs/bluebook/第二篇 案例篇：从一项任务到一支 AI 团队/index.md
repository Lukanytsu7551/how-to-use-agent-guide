# 实战案例

这里是一组从真实工作出发的 WorkBuddy 实践。不要把它当作功能清单：先选择最接近当前需求的一个案例，准备好输入资料和预期产出，再在任务完成后人工检查结果。

## 如何开始

- 第一次实践，优先从 Word、Excel、PPT 或桌面文件整理开始。
- 有持续资料处理需求，选择资讯整合、知识管理或会议协作相关案例。
- 需要复杂内容和多步骤协作时，再尝试视频、自媒体或 GEO 场景。
