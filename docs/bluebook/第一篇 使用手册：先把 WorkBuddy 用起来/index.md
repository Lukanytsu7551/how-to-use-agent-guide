# 快速上手

适合刚开始使用 WorkBuddy 的你。按顺序完成安装、登录、认识工作区和第一个任务；当你已经能稳定交付结果，再选择 Skill、连接器、外部 API、高效技巧或自动化能力继续扩展。

## 建议阅读顺序

1. 先完成 01 至 04，建立一个可正常执行、可以人工验收的最小任务。
2. 根据当前工作需要，选择 05 至 11 的能力模块，不必一次全部配置。
3. 遇到阻塞时，保留报错和环境信息，进入 [问题排查](../../workbuddy/troubleshooting.md)。
