# Codex Guide

Codex 适合需要读项目、改代码、运行命令、连接工具和完成复杂工作流的任务。这里保留原有教程内容，并按一条可执行的学习路线重新组织。

## 选择你的入口

| 模块 | 解决什么问题 | 入口 |
| --- | --- | --- |
| 学习路线 | 按从任务到交付的顺序开始 | [查看学习路线](./learning-path.md) |
| 快速上手 | 安装、账号、桌面 App、CLI 与首个任务 | [开始上手](../start/) |
| 进阶教程 | 权限、AGENTS.md、Skills、配置与团队实践 | [进入进阶](../advanced/) |

| 问题排查 | 安装、登录、使用、工具接入与反馈 | [开始排查](./troubleshooting.md) |

## 适合的任务

- 在项目中定位问题、修改代码并运行验证。
- 通过 CLI、MCP、Browser 或插件连接更多工具。
- 把任务规则、权限边界和验收方式沉淀为团队工作流。
