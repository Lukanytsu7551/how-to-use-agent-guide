# Codex 学习路线

Codex Guide 面向代码、终端和复杂工程任务。你不必先掌握所有命令：从一个边界清晰的项目任务开始，先理解项目、再执行改动、最后验证结果，逐步扩展到工具接入和团队工作流。

## 先选你的起点

| 你现在最想解决的问题 | 建议从这里开始 | 你会完成什么 |
| --- | --- | --- |
| 还没有使用过 Codex | [快速上手](../start/) | 完成安装、登录、熟悉入口并跑通第一个任务 |
| 有一个项目或具体开发问题 | [实战案例](../recipes/) | 参考真实工作流，完成可验证的产出 |
| 想接入 Skills、MCP 或自动化 | [进阶教程](../advanced/) | 建立权限、配置和工具扩展的可靠方式 |
| 遇到安装、登录、连接或执行异常 | [问题排查](./troubleshooting.md) | 收集环境与日志，按现象定位下一步 |
| 需要任务模板和官方资料入口 | [附录](./appendix.md) | 快速获取可复用的任务写法与参考链接 |

## 推荐使用路径

### 01 从一个明确任务开始

先完成安装与登录，再挑一个范围小、可以回滚和验证的任务。启动前写清楚项目目录、允许改动的文件、目标和验收方式。

**建议入口：**[快速上手](../start/)

### 02 在真实工程或工作流中复用

根据目标选择案例：文档与知识处理、浏览器自动化、设计协作、远程排障或工程发布。复用时保留输入、关键命令、修改范围和验证结果。

**建议入口：**[实战案例](../recipes/)

### 03 扩展能力并保持可控

当基础任务稳定后，再接入 AGENTS.md、Skills、Plugins、MCP、Hooks、自动化与团队配置。涉及文件写入、网络、凭据或生产环境时，必须明确审批与权限边界。

**建议入口：**[进阶教程](../advanced/)

### 04 在问题与资料之间快速回到正轨

遇到问题时，先记录版本、系统、项目目录、命令输出和脱敏日志；需要任务模板、官方文档或更新资料时，查阅附录再继续执行。

**辅助工具：**[问题排查](./troubleshooting.md) · [附录](./appendix.md)
