# Codex 学习路线

## 01 准备并开始

完成 [快速上手](../start/)，了解产品入口、安装方式和第一个低风险任务。

## 02 让任务可交付

学习 [任务设计](../start/07-task-design.md) 与 [执行和验证](../start/08-task-execution.md)，把目标、范围和验收标准写清楚。

## 03 扩展能力

进入 [进阶教程](../advanced/)，理解 Skills、Plugins、MCP、权限、配置和自动化。

## 04 在真实场景复用

从 [实战案例](../recipes/) 中选择一个接近当前工作的场景，按输入、过程、验证和风险复盘。

## 05 遇到问题时

按 [问题排查](./troubleshooting.md) 的安装、登录、使用、工具接入、反馈顺序定位。
