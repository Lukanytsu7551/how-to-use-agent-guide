# Codex 附录

这里汇总在开始任务或遇到疑问时最常用的资料入口。先明确任务目标与项目边界，再选择合适的提示词模板和官方文档，避免在不确定配置下直接执行高风险操作。

## 常用任务模板

| 场景 | 可以这样开始 |
| --- | --- |
| 了解项目 | `请先阅读项目结构，不修改文件，告诉我入口、构建命令和测试命令。` |
| 修复单一问题 | `请定位这个报错的原因，只修改必要文件，并运行相关测试验证。` |
| 评审改动 | `请检查当前改动的风险、可能回归和缺失测试，不要直接修改代码。` |
| 接入工具 | `请先说明接入这个 MCP / Skill 需要的权限、配置和验证步骤，再开始操作。` |
