# Part 5 / 多 Agent 编排

从单个 Agent 走向多个角色协作，学习如何分工、传递状态、处理失败并控制协作复杂度。

## 本部分章节

| 章节 | 本章关注点 |
| --- | --- |
| [第 13 章：编排基础](./chapter-13-orchestration) | 先明确角色、输入输出和责任边界，再决定是否拆成多个 Agent。 |
| [第 14 章：DAG 工作流](./chapter-14-dag) | 用有向无环图表达并行、依赖和汇聚，适合可预先规划的流程。 |
| [第 15 章：Swarm 模式](./chapter-15-swarm) | 理解多个相近角色如何围绕共享目标协作，以及共享状态的风险。 |
| [第 16 章：Handoff 机制](./chapter-16-handoff) | 把任务从一个专长 Agent 安全地交给另一个 Agent，避免上下文丢失。 |

## 本部分产出

完成本 Part 后，你应该能：

- 用自己的话解释本部分的关键模式，而不是只记住名词。
- 为一个真实任务画出输入、状态、动作、反馈和验收的边界。
- 说明该模式的适用条件、主要风险以及不适用时的替代方案。

## 建议学习方式

先读本页了解知识地图，再按章节顺序完成练习。每章都保留一份任务卡和一份验收记录，最后把它们合并成一个可复用的 Agent 设计说明。
