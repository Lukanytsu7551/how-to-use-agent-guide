# Agent Guide 快速上手

这一部分不要求你先写一个完整框架。你只需要先理解 Agent 的基本组成，再用一个小任务观察它如何读取上下文、选择工具、执行动作和检查结果。

## 四个起步章节

| 章节 | 重点 | 适合的练习 |
| --- | --- | --- |
| [01 / 认识 Agent](./01-agent-basics) | Agent 与普通聊天的区别 | 把一个模糊需求改写成目标、输入和结果 |
| [02 / 模型、上下文与工具](./02-three-pillars) | 三个核心组件如何配合 | 为同一任务补充上下文和工具说明 |
| [03 / Agent 的核心循环](./03-agent-loop) | 观察、决策、行动、验证 | 画出一次工具调用的运行轨迹 |
| [04 / 完成第一个可验证任务](./04-first-task) | 从任务描述到验收 | 让 Agent 交付一个可检查的小结果 |

## 建议用时

用 30–60 分钟完成四章和一个练习即可。第一次不要追求复杂：一个输入清楚、动作有限、结果可验收的任务，比一个“什么都能做”的 Agent 更适合学习。

## 开始前准备

- 选择一个你熟悉的任务场景，例如整理一份文本、提取字段或生成一个小型摘要。
- 准备一份脱敏输入资料。
- 写下结果应该满足的 2–3 条验收标准。
- 记录 Agent 的每次工具调用和最终结果，不要只看最后一句回答。
