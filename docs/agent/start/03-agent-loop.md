# 03 / Agent 的核心循环

一个可解释的 Agent 运行过程通常可以简化为：

```text
观察当前状态
    ↓
结合上下文做出下一步决策
    ↓
调用工具或生成结果
    ↓
读取反馈并验证
    ↓
继续、修正或结束
```

## 四个关键节点

- **观察**：读取用户输入、文件、工具返回值和当前状态。
- **决策**：选择下一步动作，而不是一次性猜完全部结果。
- **行动**：调用工具、写入文件、发起检索或向用户请求信息。
- **验证**：检查动作是否成功、结果是否符合验收标准。

## 为什么验证不能省略

工具调用成功不代表任务完成。文件可能写到了错误位置，检索可能拿到了过期资料，代码可能运行但没有通过测试。验证步骤是 Agent 从“自动执行”变成“可靠执行”的关键。
