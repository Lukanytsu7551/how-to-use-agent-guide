# 04 / 完成第一个可验证任务

第一次练习可以使用下面的任务模板：

```text
目标：请把这份脱敏文本整理成三列表格。
输入：我会提供一段文本和字段定义。
规则：只使用输入中的事实；缺失值标记为“待补充”；不要推测。
输出：Markdown 表格，并在最后列出无法确认的字段。
验收：每条记录都有来源片段；字段顺序不变；缺失项没有被填成猜测值。
```

## 练习步骤

1. 先让 Agent 复述目标和验收标准。
2. 再提供输入资料和字段规则。
3. 观察它是否需要工具，记录每次调用。
4. 检查结果，不满意时只修改一个变量。
5. 把成功的任务说明保存成下次可复用的模板。

## 完成标准

你不需要一次写出完美 Agent。只要能说明“它看到了什么、做了什么、结果如何被验证”，就完成了这部分的学习目标。
