# 01 / 认识 Agent

Agent 不是“会聊天的按钮”，而是一套能够围绕目标持续获取信息、做出决策并执行动作的系统。它通常包含模型、上下文、工具和一个负责推进任务的运行循环。

## Agent 与普通聊天的区别

普通聊天主要输出文本；Agent 还需要面对一个外部世界：文件、网页、数据库、代码仓库或办公系统。它必须知道当前状态，选择合适的动作，并判断动作是否产生了预期结果。

## 一个可观察的任务结构

```text
目标：整理一份脱敏会议记录
输入：会议文本、字段规则、输出模板
动作：读取、提取、校验、写入
结果：结构化表格或 Markdown
验收：字段齐全、引用可追溯、敏感信息已脱敏
```

## 先记住一个判断

如果一个任务没有清晰的目标、可用的输入和验收标准，Agent 即使给出流畅回答，也很难判断是否真的完成了工作。
