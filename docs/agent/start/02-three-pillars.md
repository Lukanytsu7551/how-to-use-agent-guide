# 02 / 模型、上下文与工具

可以先用一个简单公式理解 Agent：

> **Agent = 模型 + 上下文 + 工具**

| 组成 | 负责什么 | 常见问题 |
| --- | --- | --- |
| 模型 | 理解、推理、规划和生成 | 任务复杂度与模型能力不匹配 |
| 上下文 | 提供规则、历史、状态和外部知识 | 信息缺失、过期、冲突或太长 |
| 工具 | 读取和改变外部世界 | 描述不清、权限过大、返回值不可用 |

三者不是相互替代的关系。换一个更强的模型，不能自动补齐缺少的上下文；增加工具，也不能代替权限边界和结果校验。

## 一个实用的拆解方法

面对任何 Agent 问题，分别问三句：

1. 模型是否有能力理解并完成这类判断？
2. 上下文是否包含完成任务所需要的事实和规则？
3. 工具是否真的提供了完成动作所需的权限和反馈？
