# 附录 A / 术语表

| 术语 | 简要说明 |
| --- | --- |
| Agent | 围绕目标使用上下文和工具持续推进任务的系统 |
| Agent Loop | Agent 反复读取状态、决定下一步、执行动作并检查反馈的运行循环 |
| Context | 当前运行中提供给模型的规则、历史、状态和资料 |
| Tool | Agent 用来读取或改变外部世界的接口 |
| RAG | 先检索外部知识，再将相关内容放入上下文生成结果 |
| MCP | 连接模型与外部工具或资源的一种开放协议 |
| Skill | 可组合的任务知识、步骤、脚本和资源集合 |
| Hook | 在运行前、运行中或运行后由事件触发的校验或自动化逻辑 |
| Handoff | 将任务及其状态从一个 Agent 交给另一个 Agent |
| DAG | 用有向无环图表达任务依赖和执行顺序的工作流 |
| Harness | 围绕模型搭建的运行、工具、状态、权限和验证工程 |
| Watchdog | 用心跳、超时和进展信号监测长任务的看门狗机制 |
