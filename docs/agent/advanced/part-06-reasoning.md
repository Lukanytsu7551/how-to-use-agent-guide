# Part 6 / 高级推理

当任务需要比较多条路线、处理冲突证据或形成研究结论时，可以引入更明确的候选、复核和综合机制。

## 本部分章节框架

- 树搜索：保留多个候选路径，再根据评估结果收敛。
- Debate：让不同角色提出论据、质疑和修正。
- Research Synthesis：从多来源检索、证据分组到结论生成。
- 可靠性边界：高级推理不能替代来源、事实核验和人工判断。

## 学完后的产出

为一个研究任务设计证据表、候选结论和复核规则，而不是只要求 Agent 输出一段长文本。
