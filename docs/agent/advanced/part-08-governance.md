# Part 8 / 企业级治理

企业落地关心的不只是能力，还包括预算、权限、审计、隔离和责任边界。本部分将治理规则放到 Agent 的运行链路中，而不是在上线后再补。

## 本部分章节框架

- Token 与成本预算：为任务、用户和团队设置可解释的资源边界。
- 策略治理：把“允许做什么”转成可审计的规则。
- 沙箱与隔离：限制文件、网络、命令和数据访问范围。
- 多租户：隔离配置、数据、日志和权限，避免跨租户泄露。

## 学完后的产出

完成一份风险分级表，明确自动执行、执行前确认、强制审批和禁止执行的动作。
