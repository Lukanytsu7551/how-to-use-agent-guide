# Part 3 / 上下文与记忆

上下文决定 Agent 当前能看到什么，记忆决定它能否在不同任务和会话之间复用重要信息。本部分重点处理状态、历史、检索和过期信息。

## 本部分章节框架

- 上下文工程：规则、任务、状态、工具轨迹和外部资料分层组织。
- 记忆架构：区分事实、偏好、经验和推断，并允许修改与撤回。
- 多轮对话：管理会话状态、上下文增长和中间结论。
- 压缩与检索：减少重复信息，同时保留可验证证据。

## 学完后的产出

设计一份上下文结构，明确哪些内容长期保留、哪些按需加载，以及每条知识如何回指来源。
