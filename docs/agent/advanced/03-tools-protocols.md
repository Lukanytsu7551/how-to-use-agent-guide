# 03 / 工具、MCP 与 Skills

工具是 Agent 与外部世界之间的接口。设计工具时，应该把输入、权限、执行结果和失败方式都当成契约的一部分。

## 三个设计问题

1. 工具描述是否足够清楚，让模型知道什么时候应该使用？
2. 参数和返回值是否稳定、结构化、可验证？
3. 工具的权限是否只覆盖当前任务，而不是整个系统？

MCP 可以帮助不同 Agent 和工具服务使用更统一的连接方式；Skills 更像可组合的任务知识和操作规范。两者都不能替代权限控制和人工验收。

## 工具返回值建议

```json
{
  "ok": true,
  "data": {},
  "source": "工具或文件来源",
  "warnings": [],
  "next_action": "下一步建议"
}
```
