# Part 1 / Agent 基础

这一部分回答一个最基本的问题：Agent 与普通聊天模型有什么不同？核心不在于模型是否会生成文字，而在于系统是否能围绕目标持续读取状态、选择动作、获得反馈并推进任务。

## 本部分章节框架

- Agent 的本质：模型、上下文、工具与环境的关系。
- ReAct 循环：观察、推理、行动和验证如何连接。
- Harness 工程：模型之外的状态管理、工具编排、安全边界和交付控制。
- 模型选择：能力、成本、延迟和任务复杂度如何匹配。

## 学完后的产出

你应该能画出一个 Agent 的运行闭环，并说明一次失败更可能来自模型、上下文、工具还是流程。
