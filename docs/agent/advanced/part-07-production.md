# Part 7 / 生产架构

生产环境中的 Agent 需要面对断网、超时、重复执行、人工介入和服务升级。本部分把一次性的 Demo 转成可以恢复和追踪的工作流。

## 本部分章节框架

- 分层架构：界面、编排、工具和基础设施各自负责什么。
- 持久化工作流：保存状态，使任务可以暂停、恢复和回放。
- 重试与幂等：避免重复写入和错误级联。
- 可观测性：记录任务、工具、成本、延迟和人工修改。

## 学完后的产出

为一个长任务补上状态存储、重试策略、失败告警和人工接管入口。
