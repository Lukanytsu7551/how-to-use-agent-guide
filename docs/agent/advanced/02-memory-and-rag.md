# 02 / 记忆与知识库

记忆解决“以后还要记住什么”，RAG 解决“这次需要从哪里找到什么”。两者都不是把所有资料塞进上下文，而是建立可检索、可更新和可撤回的知识路径。

## 一次检索的基本链路

```text
用户问题 → 查询改写 → 检索候选 → 重排/过滤 → 注入上下文 → 回答与引用
```

## 先区分三种内容

- **事实**：来自资料或系统记录，需要保留来源和时间。
- **偏好**：关于用户或团队的长期习惯，需要允许修改和删除。
- **推断**：模型根据事实得出的判断，不能伪装成原始资料。

知识库上线前，至少要验证召回是否相关、引用是否准确、过期内容是否可以被替换。
