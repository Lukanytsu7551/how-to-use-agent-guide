# Part 9 / 前沿实践

前沿能力会快速变化，但背后的问题仍然可以用 Agent 三要素和运行循环来分析。本部分关注能力边界、系统成本与实际适用场景。

## 本部分章节框架

- Deep Research：多源检索、证据组织和研究报告交付。
- Computer Use：视觉定位、动作空间、反馈与权限控制。
- Agentic Coding：代码作为工具、规则和系统适配器。
- Background Agents：长时间运行、异步通知和人工接管。
- 模型路由与运行时：根据任务难度、成本和延迟选择执行策略。

## 学完后的产出

完成一份前沿能力评估表：任务适合度、输入要求、权限风险、成本、失败回退和人工验收点。
