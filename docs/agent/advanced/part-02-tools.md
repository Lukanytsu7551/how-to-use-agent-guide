# Part 2 / 工具与扩展

Agent 只有连接外部工具，才具备读取资料、执行操作和获得真实反馈的能力。本部分从工具契约开始，逐步进入协议、能力组合和异步事件。

## 本部分章节框架

- 工具调用基础：参数、返回值、错误和重试。
- MCP 协议：让 Agent 以统一方式发现和调用外部能力。
- Skills：把任务知识、步骤和资源组合成可复用能力。
- Hooks 与事件：在任务开始、执行、完成或失败时插入控制逻辑。

## 学完后的产出

完成一份只读工具的接口设计，包含最小权限、结构化返回值和失败回退策略。
