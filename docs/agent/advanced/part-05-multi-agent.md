# Part 5 / 多 Agent 编排

多 Agent 不是把一个问题拆成更多聊天窗口，而是用清晰的角色、消息和交付格式组织协作。本部分重点比较共享上下文与隔离上下文的取舍。

## 本部分章节框架

- DAG 工作流：把确定性的阶段串成可重试的有向流程。
- Supervisor：由一个协调者分配任务并汇总结果。
- Handoff：让任务在角色之间转移，同时保留必要状态。
- 失败模式：并发冲突、错误级联、重复劳动和结果无法汇总。

## 学完后的产出

先建立单 Agent 基线，再用指标证明多 Agent 在质量、速度或覆盖范围上确实带来收益。
