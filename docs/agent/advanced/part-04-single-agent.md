# Part 4 / 单 Agent 模式

复杂任务不一定需要多个 Agent。先把规划、执行、检查和修正放进一个可观察的单 Agent 循环，通常更容易建立稳定基线。

## 本部分章节框架

- Planning：把长目标拆成可执行、可验收的步骤。
- Reflection：在关键节点检查结果，而不是无条件重复。
- 推理与行动：决定哪些思考应该保留在内部，哪些需要形成外部证据。
- 停止条件：定义完成、失败、请求人工确认和回滚的边界。

## 学完后的产出

为一个长任务写出步骤状态、检查点、最大迭代次数和结束条件。
