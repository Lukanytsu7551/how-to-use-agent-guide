# Part 10 / Agent Loop 工程

长时 Agent 的难点不是让它多想几步，而是让每一步都可控、可恢复，并且不会因为上下文膨胀或工具失败而失去方向。

## 本部分章节框架

- 上下文压缩：分层保留规则、状态、证据和待办事项。
- 延迟工具加载：只在需要时暴露工具，减少选择成本和误调用。
- Tool Result 预算：控制工具返回内容，避免无关数据占满上下文。
- Prompt Cache 稳定性：把稳定规则与变化状态分开组织。
- Watchdog 与卡循环检测：识别超时、重复动作和无法收敛的轨迹。
- 并行工具执行：区分可并行动作与必须串行的依赖。

## 学完后的产出

为一个长时 Agent 设计最大运行时间、迭代上限、压缩点、超时处理和人工接管规则。
