# Part 7 / 生产级架构

把实验性的 Agent 组织成可部署、可恢复、可观测的生产系统。

## 本部分章节

| 章节 | 本章关注点 |
| --- | --- |
| [第 20 章：三层架构设计](./chapter-20-three-layer) | 拆分模型运行层、任务编排层和产品治理层，减少职责耦合。 |
| [第 21 章：Temporal 工作流](./chapter-21-temporal) | 理解持久化工作流、重试、定时和恢复对长任务的价值。 |
| [第 22 章：可观测性](./chapter-22-observability) | 记录请求、轨迹、工具、成本、延迟和质量信号，让失败可以定位。 |

## 本部分产出

完成本 Part 后，你应该能：

- 用自己的话解释本部分的关键模式，而不是只记住名词。
- 为一个真实任务画出输入、状态、动作、反馈和验收的边界。
- 说明该模式的适用条件、主要风险以及不适用时的替代方案。

## 建议学习方式

先读本页了解知识地图，再按章节顺序完成练习。每章都保留一份任务卡和一份验收记录，最后把它们合并成一个可复用的 Agent 设计说明。

**下一步：**从[第一个章节](./chapter-20-three-layer)开始。
