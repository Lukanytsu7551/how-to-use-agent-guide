# Agent Guide 学习路线

Agent Guide 现在采用“前言 → Part 概述 → 章节练习 → 附录”的书籍型结构。你不需要一次读完所有内容，只要根据当前任务选择合适的入口，再逐步补齐相关知识。

## 三条阅读路线

| 目标 | 阅读顺序 | 建议产出 |
| --- | --- | --- |
| 先建立基本判断 | [前言](./preface) → [Part 1](./part-01/) → [Part 2](./part-02/) | 一个可调用工具并完成验收的最小 Agent |
| 系统理解 Agent | Part 1 → Part 2 → Part 3 → Part 4 → Part 5 → Part 6 | 一张从模型到多 Agent 编排的知识地图 |
| 关注企业落地 | [Part 7](./part-07/) → [Part 8](./part-08/) → [Part 10](./part-10/) | 一份包含权限、预算、恢复和观测的架构说明 |

## 选择章节的方法

先看章节标题对应的“本章要解决什么”，再判断它是否直接服务于当前任务。如果遇到结果不稳定，优先检查上下文、工具返回值、验收标准和停止条件，不要一开始就增加模型或 Agent 数量。

## 每章都完成一个小闭环

1. 写清目标、输入、限制和交付格式。
2. 只开放完成任务所必需的工具。
3. 为关键动作保留运行证据。
4. 用明确标准验收结果。
5. 记录失败原因和下一次改进动作。

完整的书籍目录从[Agent Guide 首页](./)开始；历史入口仍保留在[旧版快速上手](./start/)、[旧版实战案例](./recipes/)和[旧版进阶教程](./advanced/)中，方便兼容旧链接。
