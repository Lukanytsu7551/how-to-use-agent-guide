# Agent Guide

这是一套围绕 Agent 原理、系统设计与工程实践组织的书籍型教程。它不绑定某一个产品或框架，而是带你从一个最小 Agent 开始，逐步理解工具、上下文、推理、多 Agent 编排、生产治理和长任务运行时。

你可以把它当作一张长期更新的知识地图：先建立共同语言，再通过章节练习形成设计判断，最后把方法迁移到 [Codex Guide](../codex/)、[WorkBuddy Guide](../workbuddy/) 或自己的 Agent 项目中。

## 这套教程适合谁

| 读者 | 适合获得什么 |
| --- | --- |
| 第一次系统学习 Agent 的人 | 理解 Agent 与普通问答、固定工作流的区别 |
| 正在接入工具或知识库的人 | 建立工具、上下文、记忆和验收的基本方法 |
| 需要设计多 Agent 系统的人 | 选择编排、推理、生产架构与治理模式 |
| 负责企业落地和维护的人 | 处理权限、预算、审计、恢复和长任务可靠性 |

## 推荐阅读路径

### 快速建立判断

阅读[前言](./preface)、[Part 1](./part-01/)和[Part 2](./part-02/)，完成一个带工具调用和验收标准的最小任务。

### 系统学习

按 Part 1 到 Part 8 顺序阅读。每个 Part 都先看概述，再完成章节中的练习，最后整理一张自己的设计卡。

### 面向工程落地

先读 Part 7 和 Part 8，建立生产架构、权限、成本和审计边界，再回到 Part 9、Part 10 评估前沿能力与长任务运行时。

## 贯穿式实践主线

后续章节会围绕一个“研究助手 Agent”主线持续补充案例：从资料检索开始，逐步加入工具、记忆、研究综合、人工复核、持久化和预算控制。

每完成一个阶段，都应该留下三份产出：

1. 一张任务卡：目标、输入、限制、工具和验收标准。
2. 一条运行轨迹：关键决策、工具动作、返回结果和异常。
3. 一份复盘记录：哪里有效、哪里失效、下次如何调整。
