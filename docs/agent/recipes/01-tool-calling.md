# 01 / 最小工具调用 Agent

## 任务目标

让 Agent 根据用户问题调用一个只读工具，返回结构化结果，并在工具失败时明确说明原因。

## 工作流

1. 把工具用途、参数、返回值和错误格式写清楚。
2. 让模型判断是否需要调用工具。
3. 执行工具并把结构化反馈放回上下文。
4. 根据反馈生成答案，并标明数据来源。
5. 用一条已知输入和一条异常输入分别验收。

## 关键观察

工具调用的价值不在于“让模型多做一步”，而在于把模型无法可靠知道的外部事实变成可验证输入。
