# Agent Guide 实战案例

| [02 / 文档问答与 RAG](./02-rag) | 文档分块、检索和引用 | 为什么“找到资料”不等于“答对问题” |

| [04 / 多 Agent 协作任务](./04-multi-agent) | 分工、通信与汇总 | 什么时候多 Agent 值得引入 |
