# 03 / 用 MCP 接入外部系统

## 任务目标

为 Agent 接入一个外部服务，让它可以读取指定范围的数据，同时不能执行未授权的写入动作。

## 工作流

1. 列出任务真正需要的工具和字段。
2. 为每个工具定义参数、返回值和错误。
3. 将读取与写入能力分开，并设置不同权限。
4. 用正常、缺参、超范围三组输入测试。
5. 记录调用轨迹和人工确认点。

## 关键观察

协议解决的是“怎么连接”，不是“连接后是否安全”。工具发现、权限确认和结果验证仍然属于 Agent 系统设计的一部分。
