# 02 / 文档问答与 RAG

## 任务目标

让 Agent 只依据一组资料回答问题，并在资料不足时返回“无法确认”，而不是补写不存在的事实。

## 工作流

1. 清理资料并保留标题、时间和来源。
2. 按语义和结构切分文档。
3. 根据问题检索候选片段并过滤过期内容。
4. 把片段和来源一起注入上下文。
5. 检查答案是否能回指到具体片段。

## 验收标准

- 每个关键结论都有对应来源。
- 资料中没有答案时，系统能明确拒答或请求补充。
- 更新文档后，旧版本不会继续被优先召回。
