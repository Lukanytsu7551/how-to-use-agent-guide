# 04 / 多 Agent 协作任务

## 任务目标

让一个 Agent 负责提取，一个 Agent 负责检查，最后由汇总 Agent 形成结果，并保留每一步的证据。

## 什么时候值得拆分

- 任务确实包含相互独立的角色或阶段。
- 每个角色都有清楚的输入和交付格式。
- 协作带来的质量或速度收益能够被评估。

## 最小协作结构

```text
输入资料
   ↓
提取 Agent ──→ 结构化结果
   ↓                 ↓
核验 Agent ───→ 问题清单
   ↓                 ↓
汇总 Agent ───→ 最终交付
```

如果单 Agent 已经可以稳定完成任务，不要为了“看起来更智能”而增加协作层。
