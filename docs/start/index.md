# 快速上手

适合第一次使用 Codex 的读者。先完成安装、登录和一个低风险任务；再依据自己的工作方式选择桌面 App、CLI、IDE 或 Cloud，不必一次配置所有入口。

## 建议阅读顺序

1. 先完成 01 至 06，理解 Codex、准备账号与环境，并跑通第一个任务。
2. 阅读 07 和 08，学会把目标、范围和验证标准写清楚。
3. 根据工作方式选择 09 至 14 的移动协同、CLI、IDE 或 Cloud 内容。

## 学完能做到什么

- 知道 Codex 的主要入口和适合场景。
- 能安装并打开桌面 App。
- 能把一个本地文件夹交给 Codex 处理。
- 能写出目标、范围、验证方式都清楚的任务说明。
- 能检查 Codex 的改动，知道什么时候继续追问或停止。
- 能用 CLI、VS Code 和 Cloud 进入更真实的项目任务。

完成第一个任务后，进入 [实战案例](../recipes/) 选择真实工作流，或进入 [进阶教程](../advanced/) 扩展工具和配置能力。
