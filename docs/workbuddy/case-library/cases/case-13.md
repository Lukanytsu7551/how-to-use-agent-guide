## 一、场景描述

我只跟 WorkBuddy 说了一句话："帮我获取2025年中国前十家上市公司年报数据。"这句话丢给普通搜索引擎，只会出来一堆财经网站、付费研报、零散表格。但丢给 WorkBuddy，我直接拿到：一份完整可视化报告 → 图表+数据+洞察 → 一键上线可访问。全程真实、无剧本、无多余操作。

"前十公司年报"这句话本身很模糊：按什么排？市值/营收/净利润？要哪些字段？输出什么格式？真人会反问，WorkBuddy 直接弹出选择表单，不废话、不拖延。我勾选确认，AI 立刻执行。

传统数据分析流程是搜数据 → 整理 → 做表 → 做图 → 做报告 → 发布，熟练工至少要 90 分钟。用 WorkBuddy：说需求 → 确认 → 等结果 → 上线，即使包含数据检索、生成、调试，也只需要 30 分钟。它不只是"辅助"，它直接替代了中间所有重复、繁琐、耗时的手动操作。

## 二、想要完成的任务

用一句话模糊需求驱动 WorkBuddy 自动完成 A 股市值 TOP10 上市公司年报数据的获取、可视化报告生成、移动端适配与公网部署，全程不写一行代码。

## 五、在 WorkBuddy 中的操作

### 步骤 1：提出模糊需求
我只说一句话："帮我获取2025年中国前十家上市公司年报数据。"
**关键步骤**：无需精确描述字段、格式、排序依据，直接把模糊需求丢给 WorkBuddy。

### 步骤 2：确认选项表单
WorkBuddy 不反问、不卡壳，直接弹出选择表单：排序依据（市值最大/营收最高/净利润最高/A股市值前十）、数据字段（核心三表/详细指标/对比数据）、输出格式（Excel/Markdown/可视化HTML报告）。我勾选 A股市值前十 + 可视化 HTML 报告。
**关键步骤**：在表单中勾选排序依据与输出格式，AI 立刻执行。

### 步骤 3：自动拉取数据并生成可视化报告
WorkBuddy 自动拉取 TOP10 企业核心指标：营业收入、归母净利润、总资产、净资产、净利润率、ROE。并写出全套代码：5 张专业图表（营业收入横向条形图、净利润横向条形图、总资产对比图对数刻度、净资产对比图、净利润率区间配色图）、1 张增强数据总表（10 家 × 8 字段，带排名徽章行业标签悬停高亮）、8 条关键洞察、2 张行业分布饼图。报告风格为深色主题+响应式布局+Chart.js 图表。
**关键步骤**：AI 一次性生成图表、数据表、洞察、饼图，无需额外依赖，打开即用。

### 步骤 4：移动端响应式优化
我问"手机能看吗？"WorkBuddy 直接启动本地 HTTP 服务，给出局域网地址 http://192.168.1.4:8080/a_stock_top10_2024_report.html。我反馈样式有点问题，AI 立刻自动优化：卡片 4 列 → 2 列、表格精简为 4 列、固定图表高度、增加屏幕旋转重绘。刷新即生效。
**关键步骤**：同一 WiFi 下手机直接打开完整报告，反馈样式问题后 AI 自动优化响应式布局。

### 步骤 5：Netlify 上线部署
我告诉 WorkBuddy"我要放到网上"，AI 直接推荐最快方案 Netlify Drop，并给出 3 步：打开 app.netlify.com/drop、把 HTML 文件拖进去、几秒后拿到公开链接。报告图片已内嵌 Base64，无需额外上传。
**关键步骤**：3 步完成公网部署，拿到公开访问链接。
