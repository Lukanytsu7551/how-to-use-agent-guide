# Case 94｜微信群码7天就过期？我拉着WorkBuddy把活码引流这事彻底捋清了

> **WorkBuddy 案例集 · 第 94 篇**
> 分类：内容创作与新媒体运营

---

## 一、场景描述

做公众号引流绕不开把读者往微信群里导。海报印好了，文章末尾放了二维码，菜单栏挂了入群入口——然后第 8 天有人扫码提示「二维码已过期」。微信群二维码 7 天自动过期、群满 200 人二维码直接失效，精心投放的引流码最多活 7 天。这次没自己去搜，直接把问题丢给 WorkBuddy，想看看它能帮把活码引流这事捋到什么程度。

## 二、想要完成的任务

通过六轮对话让 WorkBuddy 把微信群活码引流这事彻底捋清：有什么办法让码不过期、自建需要什么条件微信能不能识别、新群二维码是否还得手动生成、企业微信群普通用户进群有没有门槛、没营业执照能不能用外部群和客户群啥区别不是好友能拉吗、能不能做个定时提醒程序自动更新。最终理出一条可落地的执行链路。

|---|---|---|---|

## 四、前置条件

1. 已安装并登录 WorkBuddy 客户端
2. 做公众号引流有微信群码过期困扰
3. 有自己的域名（自建活码方案的前提）

## 五、在 WorkBuddy 中的操作

### 步骤 1：第一问——有什么办法让码不过期
说「我想做一个活的二维码，微信群码7天就过期了，有没有好的方案？」。WorkBuddy 先画了一张图讲清机制：对外投放的码永远不变 → 扫码后跳转到你服务器上的一个页面 → 页面展示当前有效的群二维码 → 群过期了后台换张图就行。然后给了三条路径：企业微信群活码（官方原生永久有效免费）、第三方活码工具（草料二维码等5分钟搞定）、自建活码系统（域名+静态页+换图完全可控）。
**关键步骤**：一句话提问 → 画机制图 + 给三条路径对比。

### 步骤 2：第二问——自建需要什么条件微信能识别吗
说「自建活码的话需要什么条件？微信扫我的码能识别出来吗？」。WorkBuddy 答自建需要三样：一个域名、一个托管空间（Vercel/Netlify 免费）、群二维码图片。最省事做法连数据库都不用——网页引用一张固定路径的图 current.png，群过期了把新图覆盖成同名文件。微信识别有两次：第一次扫活码识别成网页链接在内置浏览器打开 H5 页面，第二次页面里显示群二维码用户长按识别进群。域名最好做 ICP 备案。
**关键步骤**：问自建条件 → 三样东西 + 两次识别机制。

### 步骤 3：第三问——新群二维码还得手动生成
说「我有域名可以做一个静态页，但新群的二维码我需要手动去生成是吧？」。WorkBuddy 坦诚回答：是的，个人微信群码目前没有官方 API，只能在微信 App 里手动产出（群聊→右上角···→群二维码→保存到相册）。用第三方机器人自动建群出码违反微信规则封号风险高不推荐。给了减少手动次数的策略：提前批量建群轮换、过期提醒、群满了自动切到下一个。但底线是个人微信群码 7 天必过期没法自动化。想彻底不手动就是企业微信的强项。
**关键步骤**：问手动生成 → 坦诚说绕不开 + 给减少频率策略。

### 步骤 4：第四问——企业微信群普通用户进群有门槛吗
说「企业微信的群，普通微信用户加入的时候有什么条件吗？很多人对企业微信群不太感冒」。WorkBuddy 分两层回答：客观上加入几乎无门槛（不需要下载企业微信 App、群聊直接出现在个人微信里、流程和进普通群差不多），但后台要面对几个条件（企业微信账号需验证、要用客户群才能拉个人微信用户、客户群上限 500 人）。至于不感冒的顾虑正在变弱，关键在于怎么包装——群名叫「粉丝交流群」而不是「官方客户群」。
**关键步骤**：问企业微信群门槛 → 客观无门槛 + 后台条件 + 包装建议。

### 步骤 5：第五问——没营业执照能用吗外部群和客户群啥区别
说「企业要认证吗？我是个人没有营业执照如何处理？外部群和客户群有什么区别？不是好友可以拉进企业群吗？」。WorkBuddy 逐个给准话：先分清验证（免费个人实名）和认证（300元/年通常需营业执照），个人走得通的路径是先走个人实名验证解锁群活码等引流核心能力，兜底方案是办个体工商户营业执照。外部群是个大筐客户群是里面功能最强的那种，引流一定要用客户群因为群活码自动轮换只在客户群上有效。不是好友通过群活码能扫码直接进，手动拉一般不行。
**关键步骤**：问没营业执照/外部群vs客户群/不是好友 → 逐个给准话。

### 步骤 6：第六问——能不能做个定时提醒
说「怎么给我做一个定时提醒，一个码7天到期了提醒一下，我生成一个码传上去它自动更新，这个怎么做？」。WorkBuddy 理清完整链路：活码页（H5 展示当前群码图片手机端友好）+ 后台上传（带密码的简单页面不用碰代码就能换图）+ 定时提醒（到期前1~2天自动通知该换码了）+ 换码流程（微信里生成新群码→上传到后台→活码页自动更新）。整个系统核心是对外码不变后台一键换图到点自动提醒。
**关键步骤**：问定时提醒 → 理出活码页+后台上传+定时提醒+换码流程完整链路。
