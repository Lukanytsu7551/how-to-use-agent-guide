# Case 79｜从零搞懂微信表情包上架：注册·规格·流程·避坑

> **WorkBuddy 案例集 · 第 79 篇**

## 一、场景描述

最近有个想法——做一套自己的微信表情包，上架到表情开放平台，让千万微信用户都能用到。但问题来了：不会画画。PS 只会基础抠图，Procreate 更是没碰过。找设计师外包预算不允许，放弃又不甘心。于是带着这个问题去问了 WorkBuddy。它的回复比想象中详细得多，直接按「做之前需要什么 → 怎么做 → 避坑 → 变现」讲清楚了。结论：不需要是专业画师，AI 可以帮你搞定大部分工作。

## 二、想要完成的任务

通过 WorkBuddy 了解微信表情包上架的完整流程：搞清楚两种投稿方式（表情专辑 vs 表情单品）、素材规格要求（主图/缩略图/横幅/封面/聊天面板图标）、五步走流程（想好 IP → 制作表情 → 导出压缩 → 注册账号 → 提交审核）、高频被拒原因清单、变现方式，以及 WorkBuddy 能帮做什么。

## 五、在 WorkBuddy 中的操作

### 步骤 1：了解两种投稿方式
问 WorkBuddy「我想做一套微信表情包，上架到腾讯，需要什么，怎么做？」。它介绍了两种投稿方式：表情专辑（8/16/24 个，静态或动态，适合做系列打造 IP，可开赞赏）和表情单品（1 个，静态或动态，就做一个玩，不支持赞赏）。建议新手选 16 个的表情专辑，数量和丰富度的最佳平衡。
**关键步骤**：两种投稿方式对比，新手选 16 个表情专辑。

### 步骤 2：搞清楚素材规格
WorkBuddy 整理了素材规格表：表情主图 240×240 px PNG/GIF ≤500KB（真人/截屏 ≤400KB）必须透明背景；表情缩略图 120×120 px PNG ≤50KB；详情页横幅 750×400 px PNG/JPG ≤80KB；表情封面图 240×240 px PNG ≤80KB；聊天面板图标 50×50 px PNG ≤30KB。关键细节：主图必须有透明背景不能有白色底，封面图不要只露一个头用半身或全身形象，封面图不能有白色描边锯齿，动态表情时长 ≤3 秒设置循环播放。
**关键步骤**：5 类素材规格整理成表，差 1 像素都可能被拒。

### 步骤 3：了解制作方式
WorkBuddy 列了三种制作方式：手绘+软件（Procreate/PS，有绘画功底）、手机 App（醒图/Canva，新手快速出图）、AI 生成（Midjourney/即梦/WorkBuddy，零基础效率最高）。重点：WorkBuddy 可以直接帮我用 AI 生成统一风格的表情主图，调用混元或即梦直接出图，能保证风格统一。
**关键步骤**：AI 生成方式零基础效率最高，WorkBuddy 可调用混元/即梦保证风格统一。

### 步骤 4：注册账号（手把手走一遍）
打开 sticker.weixin.qq.com 点「注册账号」。第 1 步阅读注册须知（个人或企业身份均可，表情作品必须原创，含广告/二维码/品牌推广的会被判定为推广类表情不在商店展示）。第 2 步选择账号类型（个人账号需身份证实名认证，企业账号需营业执照暂不支持赞赏）。第 3 步填写注册信息（姓名/身份证号/邮箱/密码，姓名和身份证号要跟后面微信扫码验证一致）。第 4 步验证邮箱（平台发验证邮件，没收到检查垃圾箱或点重新发送间隔 26 秒）。第 5 步微信扫码验证身份（用相同真实姓名的微信扫码，微信名必须跟前面填的姓名一致）。第 6 步绑定视频号（可选，绑后表情详情页展示视频号入口，可暂时跳过）。整个注册过程大概 5 分钟搞定。
**关键步骤**：6 步注册流程，微信名必须与填的姓名一致，约 5 分钟完成。

### 步骤 5：了解高频被拒原因
WorkBuddy 列了「高频被拒原因」清单：格式搞反（静态用 PNG 动态用 GIF 别混）、尺寸不对（不是 240×240 或不是 1:1 直接打回）、文件超大（超过 500KB 的图会被拒）、封面有白边/锯齿（最容易翻车的点）、侵权（用迪士尼、明星、未授权 IP 必死）、含广告/二维码（商业推广类不展示在商店）、风格不统一（一套表情包画风乱跳审核可能不过）。
**关键步骤**：7 个高频被拒原因清单，提前避开。

### 步骤 6：了解变现方式
WorkBuddy 回答：可以，但不是暴富的路。1. 赞赏收入（开赞赏后用户下载时可打赏 1-200 元自由选，微信抽 30%）；2. IP 衍生（表情包火了延展更多系列接商业合作联名）；3. 导流价值（表情包自带传播属性热门表情包下载量可达百万级）。
**关键步骤**：三种变现方式，赞赏微信抽 30%。

### 步骤 7：确认 WorkBuddy 能帮做什么
问「那你具体能帮我做什么？」。WorkBuddy 列了 5 项：AI 生成表情主图（用混元/即梦生成统一风格 240×240 表情图）、批量处理（自动裁剪压缩到平台规格）、生成配套素材（横幅/封面/聊天面板图标自动生成）、HTML 预览（做一套预览页提交前检查效果）、文案撰写（表情名称/简介/标签词）。
**关键步骤**：WorkBuddy 可帮做 5 项工作，从生图到配套素材到文案。

## 八、验收标准

- [ ] 两种投稿方式对比：表情专辑（8/16/24 个，可开赞赏）vs 表情单品（1 个，不支持赞赏）
- [ ] 新手建议选 16 个的表情专辑
- [ ] 表情主图规格：240×240 px，PNG/GIF，≤500KB（真人/截屏 ≤400KB），必须透明背景
- [ ] 表情缩略图规格：120×120 px，PNG，≤50KB
- [ ] 详情页横幅规格：750×400 px，PNG/JPG，≤80KB
- [ ] 表情封面图规格：240×240 px，PNG，≤80KB，不能有白边/锯齿
- [ ] 聊天面板图标规格：50×50 px，PNG，≤30KB
- [ ] 动态表情时长 ≤3 秒，设置循环播放
- [ ] 三种制作方式：手绘+软件（Procreate/PS）、手机 App（醒图/Canva）、AI 生成（Midjourney/即梦/WorkBuddy）
- [ ] 注册流程 6 步：阅读须知 → 选择类型 → 填写信息 → 验证邮箱 → 微信扫码 → 绑定视频号（可选）
- [ ] 个人账号需身份证实名认证，企业账号需营业执照暂不支持赞赏
- [ ] 微信扫码验证时微信名必须与前面填的姓名一致
- [ ] 整个注册过程大概 5 分钟搞定
- [ ] 7 个高频被拒原因：格式搞反/尺寸不对/文件超大/封面白边锯齿/侵权/含广告二维码/风格不统一
- [ ] 变现方式：赞赏收入（1-200 元微信抽 30%）、IP 衍生、导流价值
- [ ] WorkBuddy 能帮做 5 项：AI 生成主图、批量处理、生成配套素材、HTML 预览、文案撰写
