# Case 30｜AI 帮我填表，白嫖小米百万 Token

> **WorkBuddy 案例集 · 第 30 篇**
> 分类：办公协同与效率提升

---

## 一、场景描述

最近小米 AI 开放平台推出了"MiMo 百万 Token 激励计划"，免费送 100 万亿 Token。从找到活动信息、到填完表单，全程靠这个 skill 处理。下面记录下整个过程，顺便聊聊这个 skill 的更多用法。

我随口问了一句："小米的免费 Token 如何领取？"它连搜索框都没打开，直接给我整理好了：活动主页、API 平台、活动时间（4 月 28 日-5 月 28 日，赠完即止）、怎么领（填申请表单→等 3 个工作日→收到邮件→Token 到账）。不需要我翻网页、逐字抄，一问一答，信息全齐了。

活动页有一张复杂的申请表单，需要邮箱、AI 工具、底层模型、项目描述……我直接问它："你能帮我填写吗？"它二话不说，用 playwright-cli 技能接管了我的浏览器。它先问我要了邮箱，然后批量填写所有字段。整个过程，我只提供了我的邮箱。当然，验证码这道坎绕不过去——AI 完成 90% 的工作，我只需要动一下手指滑动验证码。最好的协作不是替代，是分工。

## 二、想要完成的任务

用 WorkBuddy 的 playwright-cli 技能，从查询小米 MiMo 百万 Token 激励计划活动信息，到自动填写复杂申请表单（邮箱/AI 工具/底层模型/项目描述），完成 Token 申领全流程。

|---|---|---|---|

## 四、前置条件

1. 已安装并登录 WorkBuddy 客户端
2. 已安装 playwright-cli 技能
3. 本机已安装 Chrome 浏览器
4. 已有可用邮箱地址（用于接收 Token 通知）
5. 已有 GitHub 链接（用于项目描述）
6. 理解验证码需要人工完成（AI 无法自动过验证码）

## 五、在 WorkBuddy 中的操作

### 步骤 1：一句话查询活动信息
我随口问了一句："小米的免费 Token 如何领取？"它连搜索框都没打开，直接给我整理好了：活动主页（https://100t.xiaomimo.com/）、API 平台（https://platform.xiaomimo.com/）、活动时间（4 月 28 日-5 月 28 日，赠完即止）、怎么领（填申请表单→等 3 个工作日→收到邮件→Token 到账）。不需要我翻网页、逐字抄，一问一答，信息全齐了。
**关键步骤**：一句话查询，AI 直接整理出活动主页、API 平台、时间、领取方式 4 项信息。

### 步骤 2：让 AI 用 playwright-cli 接管浏览器填表
活动页有一张复杂的申请表单，需要邮箱、AI 工具、底层模型、项目描述……我直接问它："你能帮我填写吗？"它二话不说，用 playwright-cli 技能接管了我的浏览器。它先问我要了邮箱——这是最让我意外的一点，它没有瞎填，而是先问："你的邮箱地址是什么？"我告诉它：wwwczgedu@126.com。
**关键步骤**：让 AI 用 playwright-cli 接管浏览器，AI 先确认邮箱再填表（不瞎填）。

### 步骤 3：AI 批量填写所有字段
确认身份后，它开始批量填写所有字段：AI 工具选了 Claude Code、Cursor、OpenClaw，底层模型勾了 Claude、DeepSeek、GPT，项目描述自动生成了近 300 字，还附上了 GitHub 链接。整个过程，我只提供了我的邮箱。
**关键步骤**：AI 批量填写 AI 工具、底层模型、项目描述（近 300 字）+GitHub 链接，用户只提供邮箱。

### 步骤 4：切换可见模式亲眼看到 AI 操作
第一次提交时系统弹出了滑块验证，AI 脚本直接卡死——它能填表，但过不了验证码。我让它切换到可见模式："你能不能打开浏览器，填写，让我看到？"它立刻把 Chrome 窗口弹出来，我能亲眼看到它逐字段填写、勾选选项、敲入文本。
**关键步骤**：遇到滑块验证卡死时，切换可见模式，亲眼看到 AI 逐字段操作。

### 步骤 5：人工完成验证码并提交成功
更离谱的是——提交时又弹了一次验证码。这次它直接告诉我：验证码又弹出了，你自己在浏览器里完成滑块验证然后提交吧。最后一步是我自己滑动验证，然后点击提交。成功了。现在坐等邮件通知，通过后用 wwwczgedu@126.com 登录平台领 Token。
**关键步骤**：人工完成滑块验证并点击提交，坐等邮件通知后登录平台领 Token。
