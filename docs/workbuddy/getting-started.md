建议按“下载与安装 -> 登录与更新 -> 认识任务和工作区 -> 完成第一个任务”的顺序开始。

- [官方蓝皮书：使用手册](https://workbuddy.homes/bluebook/)
- [开源指南：下载、安装、登录与更新](https://github.com/AlephAITech/WorkBuddyGuide)

在开始前，请确认安装来源、产品版本、账号状态和可访问网络；这些信息也是后续排查时最重要的上下文。
