# WorkBuddy 学习路线

## 01 先用起来

完成安装、登录，熟悉任务与工作区。详见 [快速上手](./getting-started.md)。

## 02 从一项真实工作开始

选择资料整理、办公协作或信息处理等低风险任务，明确输入、输出和人工核对点。

## 03 让工作可复用

了解 Skill、连接器、外部 API 与自动化，详见 [进阶教程](./advanced.md)。

## 04 沉淀为工作系统

用案例记录任务背景、步骤、验证结果和可复用模板，详见 [实战案例](./recipes.md)。

## 05 持续排查和更新

遇到阻塞时按 [问题排查](./troubleshooting.md) 记录环境、日志与复现步骤。
