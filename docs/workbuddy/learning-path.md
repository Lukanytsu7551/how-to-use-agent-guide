# WorkBuddy 学习路线

WorkBuddy Guide 面向办公、资料处理与桌面自动化。你不需要先记住所有功能：从一项真实工作开始，先跑通、再复用，逐步把 Agent 变成可靠的工作伙伴。

## 先选你的起点

| 你现在最想解决的问题 | 建议从这里开始 | 你会完成什么 |
| --- | --- | --- |
| 还没有使用过 WorkBuddy | [快速上手](./getting-started.md) | 完成安装、登录、工作区设置和第一个任务 |
| 有一项具体的办公工作要处理 | [实战案例](./recipes.md) | 用真实输入产出一份可以人工验收的结果 |
| 已经跑通任务，想提高效率 | [进阶教程](./advanced.md) | 把方法沉淀为 Skill、自动化或协作流程 |
| 遇到安装、登录或工具接入问题 | [问题排查](./troubleshooting.md) | 按现象记录信息并定位下一步 |
| 需要常用输入写法或场景参考 | [附录](./appendix.md) | 快速找到可调整的模板和能力边界 |

## 推荐使用路径

### 01 从第一个真实任务开始

先完成安装与登录，认识工作区、任务和结果交付方式。第一次任务不必复杂，优先选择资料整理、会议纪要、文件归档或一份可检查的办公产物。

**建议入口：**[快速上手](./getting-started.md)

### 02 用案例找到适合你的工作方式

根据当前工作选择案例：文档、表格、PPT、文件整理、信息汇总、会议协作或内容生产。先明确输入资料、预期产出和人工核对点，再交给 WorkBuddy 执行。

**建议入口：**[实战案例](./recipes.md)

### 03 把一次成功变成可复用流程

当任务稳定后，再学习 Skill、连接器、自动化与多 Agent 协作。把高频步骤、输入模板和验收标准沉淀下来，避免每次都从零开始描述任务。

**建议入口：**[进阶教程](./advanced.md)

### 04 在长期使用中保持可控

涉及连接器、外部工具、自动化或跨团队协作时，明确权限范围、人工确认点和失败回退。遇到问题时，保留版本、环境、复现步骤与脱敏日志，才能快速得到有效帮助。

**辅助工具：**[问题排查](./troubleshooting.md) · [附录](./appendix.md)
