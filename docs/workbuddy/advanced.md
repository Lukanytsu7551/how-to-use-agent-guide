# WorkBuddy 进阶教程

当你已经能稳定完成一个任务后，再逐步接入可复用能力：

1. Skill：把重复方法固化为可调用流程。
2. 连接器：在授权边界内连接资料和协作工具。
3. 外部 API：明确密钥、费用、数据权限与失败回退。
4. 自动化与多 Agent：为长流程设置检查点与人工复核。

推荐从 [WorkBuddy 实战蓝皮书](https://workbuddy.homes/bluebook/) 的进阶章节开始，并随产品版本变化核对原文。
