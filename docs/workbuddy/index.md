# WorkBuddy Guide

WorkBuddy 适合把日常资料、办公协作和重复流程交给 Agent 推进。本栏目以真实任务为线索整理使用路径；具体教程持续依据官方资料与开源教程核验补充。

| 问题排查 | 按阶段定位安装与使用问题 | [开始排查](./troubleshooting.md) |

## 使用边界

在处理文件、账号、第三方服务或自动化任务时，请先确认数据范围、授权权限与人工复核点。涉及敏感资料时，优先使用脱敏样本验证流程。
