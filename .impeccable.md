# How to Use Agent - Design Context

## Purpose

How to Use Agent is a tutorial center that helps people choose, understand,
begin using, and steadily improve with Codex, WorkBuddy, or agent systems in
general.

## Audience and Jobs

- People evaluating which Agent suits their work before investing time in setup.
- Learners who want a book-style foundation in agent principles and engineering.
- Learners who need a clear route from first use to real cases, advanced topics,
  and troubleshooting.
- Teams looking for reliable, reusable working methods rather than product hype.

## Brand Personality

Rational, professional, calm, and tool-like. The site should feel useful on a
workday: clear enough for first-time learners, precise enough for technical
users, and never marketing-heavy or overly playful.

## Design Direction

Editorial builder-tool: deep forest green for the decision moment, warm tinted
  paper for focused reading, and restrained Codex blue / WorkBuddy green only
where product identity or action needs differentiation. The Agent Guide uses a
book-like hierarchy so readers can move from foundations to runtime engineering.

## Non-negotiable Contracts

- Keep the Codex / WorkBuddy distinction visible while presenting Agent Guide as
  the shared foundation, without splitting the site into competing visual brands.
- Keep the Agent Guide primary structure visible: preface, Parts 1–10, chapters,
  and appendices.
- Preserve all existing tutorial routes, navigation labels, markdown content,
  search, theme switching, and collapsible document directories.
- Avoid generic SaaS gradients, oversized decorative cards, false metrics, and
  decorative motion.
